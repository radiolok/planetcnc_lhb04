# План работ — mpgd

Адаптер USB-HID пульта **XHC LHB04** (и клонов, напр. KTURT) ↔ **PlanetCNC TNG**
(контроллеры Mk3/4). Демон читает кнопки и маховик, джогает оси, обновляет
LCD пульта и обрабатывает кнопки по YAML-конфигу.

Дата последнего обновления: 2026-08-15

---

## Текущий статус

Основной функционал v1 реализован и собирается под Windows; проверен на реальном
пульте (клон KTURT, 6-байтовые пакеты) вместе с обратной связью на LCD. Остались
валидация на реальном контроллере PlanetCNC, приёмка и перенос на Linux.

## Выполнено

- [x] Чтение пульта — HID report `0x04` (8 байт у XHC, 6 байт у клонов KTURT),
      100 Гц, debounce кнопок, накопление импульсов маховика.
- [x] LCD-дисплей пульта — feature report `0x06`, кодирование по эталону
      LinuxCNC `xhc-hb04` (42 байта → 6×8 отчётов).
- [x] Открытие коллекций входа и дисплея отдельно (Windows перечисляет пульт
      как несколько HID-коллекций; выбор write-узла пробой feature report).
- [x] Джог маховиком — режимы Step/Continuous, выбор оси (X/Y/Z/A), шаг
      0.001/0.01/0.1/1.0 мм, клампинг накопленных импульсов.
- [x] Override подачи и шпинделя (положения Feed/Spindle).
- [x] Кнопки — 18 кнопок, сопоставление «кнопка → действие» в YAML.
- [x] Авто-переподключение USB (2 с) и graceful shutdown (Ctrl+C/SIGTERM).
- [x] Режимы интеграции: in-process GUI, headless, profile, attach.
- [x] Диагностическая GUI-утилита `mpg_gui` (Dear ImGui) с чтением сырых
      пакетов и обратной связью на LCD.
- [x] Unit-тесты: packet parser, jog controller, display updater + planetcnc
      logic (JogController / ButtonHandler / StateReader / DisplayUpdater через
      mock `ITngApi`) — ctest 4/4.
